# Org template releases

This repository holds released Org and Company template files for OrgsOS, and nothing else.

- It is read-only for everyone outside the platform. Only the platform release job writes here.
- The release job publishes on a release tag, and only after that release's file-list and leak checks pass.
- A published version is never overwritten. Fixes ship as a new version.

Created on Human Root's ruling TEMPLATE-RELEASES-REPO-356 (28 October 2026).
